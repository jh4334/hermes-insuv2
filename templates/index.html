모두의 인수인계 · 로컬-first 업무 준비 도구

공문 PDF를 업무 카드와 캘린더 흐름으로 바꾸는 준비판

정식 화면은 번들된 React 프론트엔드에서 실행됩니다. 원본 PDF는 앱 DB/영구 저장소에 저장하지 않고, 문서번호 + 기안일 + 참고자료 위치 중심으로 올해 업무 실행판을 준비합니다.

PDF 업로드 캘린더 업무목록 내보내기

프론트엔드 빌드가 필요합니다

배포용 실행 파일에서는 새 프론트엔드가 열립니다. 개발 환경에서 이 화면이 보이면 frontend/dist가 아직 없거나, 정적 프론트엔드가 연결되지 않은 상태입니다.

  • 최종 사용자는 압축을 풀고 모두의인수인계.exe만 더블클릭하면 됩니다.
  • 업무 입력은 PDF 업로드 흐름을 기준으로 하며, PDF 업로드 → 추출 결과 확인 → 캘린더/업무목록 확인 순서로 진행합니다.
  • 내보내기에서는 로컬 백업, 업무묶음 DOCX, 업무묶음 Markdown을 사용할 수 있습니다.
