# 모두의 인수인계 Product Brief

## One-line concept

전년도 공문 PDF를 올해 업무 실행판으로 바꾸는 로컬-first 공문 기반 캘린더 앱.

## Product frame

모두의 인수인계는 대시보드나 별도 문서 작성기가 아니라, 공문 흐름을 달력 위에서 다시 확인하는 도구다. 앱은 후보를 제시하고, 교사 직접 점검을 통해 올해 업무 일정을 정리한다.

## MVP user story

1. 사용자가 전년도 공문 PDF를 업로드한다.
2. 앱이 기안일, 제목, 담당자, 문서번호 후보를 추출한다.
3. 사용자는 추출 결과를 확인·수정하고 업무묶음 이름을 붙인다.
4. 연간 흐름에서 바쁜 달과 업무묶음별 분포를 본다.
5. 월별 캘린더에서 날짜별 업무를 확인하고 필요하면 날짜를 옮긴다.
6. 업무목록에서 문서번호·담당·참고자료 위치와 메타데이터 보완 상태를 정리한다.
7. 필요할 때 후임자 참고 메모를 적고 업무묶음 DOCX 또는 업무묶음 Markdown으로 내보낸다.

## Core surfaces

- 캘린더: PDF 업로드, 추출 결과 확인, 업무묶음 관리, 연간 흐름, 월별 캘린더
- 업무목록: 문서번호, 담당, 참고자료 위치, 보완 필요, 교사 직접 점검, 후임자 참고 메모
- 내보내기: 로컬 백업, 업무묶음 DOCX, 업무묶음 Markdown, HWPX 추후 지원 안내

## Non-goals

- 첨부파일 저장소
- 공문 자동 수집 또는 감시 폴더
- OCR 설치 마법사
- 별도 인수인계 문서 작성을 강요하는 UX
- 허위 효과 측정값 만들기
- 원본 PDF 영구 보관

## Privacy and safety

- 원본 PDF는 앱 DB/영구 저장소에 저장하지 않는다.
- 백업과 내보내기는 업무 카드 메타데이터, 메타데이터 보완 상태, 후임자 참고 메모 중심이다.
- 일정·문서번호·담당은 확정값이 아니라 후보이며, 교사가 직접 점검하는 것을 전제로 한다.
