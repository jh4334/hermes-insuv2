# Current Task

Create the new `hermes-insu` repository as a concept-reset successor to `codex-insu`.

## Initial MVP slice

1. Accept pasted previous-year document metadata lines.
2. Extract date, document number, title, and owner.
3. Roll dates/titles forward to the target year.
4. Render an operations board and month-load summary.
5. Show handover only as optional post-it style reference memo.
6. Keep raw file storage and attachment DB out of scope.

## Near-term next iterations

1. Replace pasted text with PDF upload/preview pipeline.
2. Add editable extraction preview table.
3. Add calendar/year-grid view.
4. Add export to Excel/HTML/printable handover support packet.
5. Add Windows EXE packaging only after concept/UI stabilizes.
