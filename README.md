# 모두의 인수인계

**전년도 공문 PDF를 올해 업무 실행판으로 바꾸는 로컬-first 공문 기반 캘린더 앱**

모두의 인수인계는 학교 담당자가 전년도 공문 PDF를 올리고, 추출 결과를 직접 확인·수정한 뒤, 올해 기준 업무묶음·연간 흐름·월별 캘린더·업무목록을 정리하는 로컬형 업무 지원 도구입니다.

최종 사용자는 개발 도구를 설치하지 않습니다.

```text
압축 풀기 → 모두의인수인계.exe 더블클릭 → PDF 업로드 → 추출 결과 확인 → 달력/업무목록 확인 → 내보내기
```

## V2 핵심 기능 (기획 문서: docs/handover_v2_planning.md)

- **투트랙 토글**: 첫 실행 시 인계자("내 업무 정리해 넘기기") / 인수자("받은·작년 자료 파악하기")를 선택합니다. 문구와 기본 화면만 다르고 데이터 모델·엔진은 하나를 공유합니다.
- **일단 다 쏟고, 구조도에서 정리**: 업로드할 때 업무묶음 이름을 강제하지 않습니다. 카드 무더기에 자동 분류가 단계·세부업무 후보를 제안하고, "이렇게 나눴어요" 검토 화면에서 이름수정·병합 후 일괄 확인합니다.
- **자동 분류 엔진**: 단계(계획 → 심의·협의 → 품의 → 결과보고)는 제목 키워드 규칙, 세부업무는 키워드 클러스터링 제안, 확신 낮은 카드는 미분류 인박스로 보냅니다.
- **오답 학습(로컬 규칙 메모리)**: 사람이 카드를 옮기거나 묶음을 확정하면 키워드 → 세부업무/업무 규칙을 기억해 다음 업로드부터 자동 배치합니다. 완전 오프라인으로 동작합니다.
- **업무 구조도**: 업무 > 세부업무 > 단계 흐름 스윔레인. 미분류 인박스, 드래그 재배치, 세부업무 이름 수정, 업무 버킷 배정, 자동 점검(결과보고 미등록 등)을 제공합니다.

## 핵심 흐름

1. **캘린더**
   - PDF 업로드
   - 추출 결과 확인·수정
   - 자동 분류 제안 확인 (묶음 이름 강제 입력 없음)
   - 연간 흐름과 월별 캘린더 확인
   - 주말·공휴일 후보는 교사가 최종 확인
2. **업무목록**
   - 문서번호, 기안일, 담당, 참고자료 위치 확인
   - 메타데이터 보완
   - 후임자 참고 메모 입력
3. **내보내기**
   - 로컬 백업 저장/가져오기
   - 업무묶음 DOCX 생성
   - 업무묶음 Markdown 저장
   - HWPX는 추후 지원 예정

## 제품 원칙

- 원본 PDF는 앱 DB/영구 저장소에 저장하지 않습니다.
- 백업 파일에는 업무 카드, 업무묶음, 메타데이터 보완 상태, 후임자 참고 메모, 참고자료 위치만 담습니다.
- 일정·문서번호·담당은 후보로 제시하고, 최종 판단은 교사가 합니다.
- 공문을 자동으로 모으는 기능은 넣지 않습니다.
- 최종 사용자에게 Python, pip, npm, 터미널, OCR 설치를 요구하지 않습니다.

## 개발 실행

개발자는 아래 명령으로 로컬 검증을 할 수 있습니다.

```bash
python3 app.py
cd frontend
npm install
npm run dev
```

Vite 개발 서버는 `/api` 요청을 `http://127.0.0.1:5001`로 프록시합니다.

## 개발 검증

```bash
PYTHONPATH=. python3 -m pytest -q
PYTHONPYCACHEPREFIX=/tmp/hermes-insu-compile-cache python3 -m compileall -q app.py run_local.py build_exe.py hermes_insu tests
cd frontend && npm test -- --run && npm run build
cd .. && git diff --check
```

## 연구대회 문장

> 전년도 공문 흐름을 기반으로 새 담당자가 올해 놓치기 쉬운 업무 시점·후속처리·결과보고를 미리 확인하는 로컬형 업무 인수인계 도구

## 개인정보/보안 원칙

- 실제 학생·학부모·교직원 개인정보를 샘플 코드나 테스트에 넣지 않습니다.
- 예시는 `샘플초등학교`, `업무지원과-0000`, `담당자 확인` 같은 가상 데이터만 사용합니다.
- 원문은 `문서번호 + 기안일 + 참고자료 위치`로 다시 찾게 합니다.
- 원본 PDF 바이트나 전체 추출 원문을 백업/내보내기 파일에 담지 않습니다.
